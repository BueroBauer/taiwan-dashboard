<tasks>

<task type="auto">
  <name>Task 1: Repo erstellen + Remote setzen + Push</name>
  <files>.git/config</files>
  <action>
    Führe folgende Befehle sequenziell aus — bei Fehler stoppen und melden:

    1. Repo erstellen:
       `gh repo create BueroBauer/taiwan-dashboard --public --description "Taiwan Reise-Dashboard 2026/27"`

    2. Remote setzen (nur wenn noch kein origin vorhanden):
       `git remote add origin https://github.com/BueroBauer/taiwan-dashboard.git`
       Falls origin bereits existiert: `git remote set-url origin https://github.com/BueroBauer/taiwan-dashboard.git`

    3. Alle Files stagen und committen falls uncommitted changes vorhanden:
       `git status --short` prüfen — falls Output nicht leer:
       `git add -A && git commit -m "chore: initial deploy"`

    4. Push:
       `git push -u origin main`

    Kein Force-Push. Wenn Push scheitert: Fehlermeldung melden, nicht überschreiben.
  </action>
  <verify>
    <automated>gh repo view BueroBauer/taiwan-dashboard --json name,url --jq '"Repo: " + .name + " — " + .url'</automated>
  </verify>
  <done>Repo existiert auf GitHub, main Branch enthält alle Files</done>
</task>

<task type="auto">
  <name>Task 2: GitHub Pages aktivieren + URL verifizieren</name>
  <files></files>
  <action>
    1. Pages aktivieren via API:
       `gh api repos/BueroBauer/taiwan-dashboard/pages -X POST -f source[branch]=main -f source[path]=/`

       Falls Pages bereits aktiviert (HTTP 409): ignorieren, weiter zu Schritt 2.

    2. Pages-URL abrufen:
       `gh api repos/BueroBauer/taiwan-dashboard/pages --jq '.html_url'`

    3. Warten bis Pages erreichbar — max 5 Minuten. Nach 60 Sekunden prüfen:
       `curl -s -o /dev/null -w "%{http_code}" https://BueroBauer.github.io/taiwan-dashboard/`

       Erwartet: 200. Falls noch nicht bereit (404): nochmal nach 60s prüfen.
       Nach 5 Minuten ohne 200: Fehlermeldung melden mit aktuellem HTTP-Status.

    4. Finalen Status ausgeben: URL + HTTP-Code.
  </action>
  <verify>
    <automated>curl -s -o /dev/null -w "%{http_code}" https://BueroBauer.github.io/taiwan-dashboard/ | grep -q "200" && echo "PASS: HTTP 200" || echo "PENDING or FAIL"</automated>
  </verify>
  <done>https://BueroBauer.github.io/taiwan-dashboard/ antwortet mit HTTP 200</done>
</task>
