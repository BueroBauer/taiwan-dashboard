Neue Datei js/booking.js erstellen. Exakt nach restaurants.js-IIFE-Muster (var, function(){}, keine Arrow Functions, keine Template Literals, keine const/let).

Struktur:
- window.bookingModule = IIFE
- init(): Guard auf window.TAIWAN und window.TAIWAN.booking + Element 'booking-content'. el.innerHTML = ''. Dann _render(el) aufrufen. console.log('[booking.js] initialisiert (10 Phasen)').
- _render(container): Baut '<div class="bkg-grid">' + alle Cards + '</div>', dann insertAdjacentHTML('beforeend', html) auf container. NICHT innerHTML +=.
- _makeBookingCard(b): Baut HTML-String fuer eine Phase:
  1. earlyBadge: wenn b.earlyBook === true dann '<span class="bkg-badge bkg-badge--warn">&#x26A0;&#xFE0F; Fr&#xFC;h buchen!</span>' sonst ''
  2. Phase-Header mit phaseId, region, earlyBadge
  3. Daten-Zeile: b.checkIn + ' &ndash; ' + b.checkOut + ' (' + b.nights + ' N&#xE4;chte)'
  4. criteria.notes als Text
  5. Zwei Link-Buttons nebeneinander:
     - 'Research starten' href=b.bookingUrl target='_blank' rel='noopener' class='bkg-link bkg-link--primary' (BKG-03: direkt bookingUrl verwenden)
     - '&#x1F3E0; Airbnb &#x2197;' href=b.airbnbUrl target='_blank' rel='noopener' class='bkg-link bkg-link--secondary'
  6. _renderExampleHotels(b.exampleHotels) aufrufen
  7. _renderKKdayTours(b.phaseId) aufrufen
- _renderExampleHotels(hotels): Wenn hotels.length === 0: '<div class="bkg-hotels-empty">Hotels noch nicht eingetragen</div>' zurueckgeben. Sonst: Hotels-Grid mit Name, Preis, Link. (Leer-Fallback ist das Wichtige fuer Phase 5.)
- _renderKKdayTours(phaseId): Filtert window.TAIWAN.tours nach t.phaseId === phaseId. Wenn keine: '' zurueckgeben. Sonst pro Tour:
  - Platzhalter-Erkennung: var isPlaceholder = !/\d/.test(t.url)
  - Wenn isPlaceholder: Hinweistext '<span class="bkg-tour-placeholder">&#x26A0; URL Platzhalter &mdash; echte KKday-URL in data.js eintragen</span>'
  - Sonst: '<a href="..." target="_blank" rel="noopener">Buchen &#x2197;</a>'
  - buggyFriendly: wenn true '&#x1F6BC;' (Kinderwagen-kompatibel), wenn false '&#x1F6BC;&#x26A0;' (Kinderwagen-Einschraenkung)
  - Felder anzeigen: t.name, t.provider, 'ab &euro;' + t.priceEur, buggy-Icon, Link-oder-Hinweis, t.note
  </action>
