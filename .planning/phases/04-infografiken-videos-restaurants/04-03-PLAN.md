    _renderFilterButtons(container):
    - HTML: `<div class="rst-filters">`
    - Erster Button: `<button class="rst-filter rst-filter--active" data-phase="all">Alle</button>`
    - Dann forEach window.TAIWAN.phases:
      `<button class="rst-filter" data-phase="` + p.id + `">Phase ` + p.id + ` ` + p.name + `</button>`
    - Schließen: `</div>`
    - `container.insertAdjacentHTML('beforeend', html);`

    _filter(phaseId):
    - `if (phaseId === 'all') return window.TAIWAN.restaurants;`
    - `return window.TAIWAN.restaurants.filter(function(r) { return r.phaseId === phaseId; });`
    - WICHTIG: phaseId beim Vergleich als Number — beim Event: `parseInt(btn.getAttribute('data-phase'), 10)`

    _renderCards(container, phase):
    - Alten Grid entfernen: `var old = container.querySelector('.rst-grid'); if (old) old.remove();`
    - Daten filtern: `var items = _filter(phase === 'all' ? 'all' : parseInt(phase, 10));`
    - HTML-String: `var html = '<div class="rst-grid">';`
    - forEach items: `html += _makeCard(r);`
    - `html += '</div>';`
    - `container.insertAdjacentHTML('beforeend', html);`

    _makeCard(r):
    - typeLabel: `{ 'vegan': '🌱 Vegan', 'vegetarisch': '🥗 Vegetarisch', 'veg-option': '✓ Veg-Option' }`
    - namePrefix: `r.veganSymbol ? '🌱 ' : ''`
    - Return:
      `'<div class="rst-card">' +`
      `'<div class="rst-name">' + namePrefix + r.name + '</div>' +`
      `'<div class="rst-meta">' +`
        `'<span class="rst-type">' + (typeLabel[r.type] || r.type) + '</span>' +`
        `'<span class="rst-price">€' + r.pricePerPerson.eur + '/P</span>' +`
      `'</div>' +`
      `'<div class="rst-note">' + r.note + '</div>' +`
      `'<a class="rst-link" href="' + r.googleMapsUrl + '" target="_blank" rel="noopener">Google Maps ↗</a>' +`
      `'</div>'`

    _bindEvents(container):
    Event Delegation — ein Listener:
    ```javascript
    container.addEventListener('click', function(e) {
      var btn = e.target.closest('.rst-filter');
      if (!btn) return;
      var phase = btn.getAttribute('data-phase');
      _currentPhase = phase;
      container.querySelectorAll('.rst-filter').forEach(function(b) {
        b.classList.remove('rst-filter--active');
      });
      btn.classList.add('rst-filter--active');
      _renderCards(container, phase);
    });
    ```

    Wichtig:
    - phaseId-Vergleich: `parseInt(phase, 10)` beim Vergleich mit r.phaseId (Number)
    - 'all' bleibt String, nur Phasen-IDs werden parseInt
    - Alle externen Links: target="_blank" rel="noopener"
    - Kein Template Literal, kein Arrow Function (ES5)
